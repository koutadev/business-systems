# business-systems

ポートフォリオ用の業務システム群開発を、プロジェクトマネジメントの観点で進行管理するリポジトリ。
各システムの実装は個別リポジトリ（laravel-business-template / crm-sales 等）で行い、本リポジトリでは進捗・課題・意思決定・リリースを一元管理する。

## 進行管理ドキュメント（docs/pm/）
- [01_progress.md](docs/pm/01_progress.md) … 進捗管理表（システム別ステータス・進捗率・マイルストーン）
- [02_issues.md](docs/pm/02_issues.md) … 課題管理表（課題・リスクの記録と解決追跡）
- [03_decisions.md](docs/pm/03_decisions.md) … 意思決定ログ（設計・方針の判断記録）
- [04_releases.md](docs/pm/04_releases.md) … リリース・変更履歴（pushごとのログ）
